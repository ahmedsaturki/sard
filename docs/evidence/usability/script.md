# HC-13 Usability Test Script — Client Handoff Panel

**Target:** 5 agency owners + their real clients (non-technical, Arabic-speaking)
**Task:** "Update your homepage text and publish"
**Success Criteria:** >= 4/5 complete unaided in < 3 minutes
**Environment:** Sard Lite admin on localhost (or staging)

## Test Setup (5 minutes)
1. Participant logs into Sard Lite admin (pre-created account: editor role)
2. Facilitator explains: "Imagine you're the client who just received this site from your agency. You want to update the homepage headline."
3. No further guidance unless participant asks (then note the question)

## Test Script (15 minutes per participant)

### Introduction (2 min)
- "Thank you for participating. This tests how easy it is for clients to manage their Sard sites."
- "You'll see a simplified panel called 'إدارة الموقع' (Site Management)."
- "Task: Change the homepage headline to 'مرحباً بكم في موقعنا الجديد' and publish."
- "Think aloud as you go. There are no wrong answers."

### Task Execution (8 min max)
**Start timer when participant first sees the panel.**

Observe and note:
- [ ] Finds "إدارة الموقع" in sidebar
- [ ] Identifies homepage content block
- [ ] Clicks to edit (understands click-to-edit)
- [ ] Types Arabic text correctly (RTL input)
- [ ] Sees live preview update
- [ ] Finds "نشر" (Publish) button
- [ ] Confirms publication success
- [ ] Time to complete: _____ seconds

### Post-Task Questions (5 min)
1. "How easy was that? (1-5 scale: 1=very hard, 5=very easy)"
2. "What was confusing?"
3. "What would you change?"
4. "Would you feel confident doing this alone next time?"
5. "Any Arabic text direction issues?"
